# Ludo rules (engine)

## Shared
- 2–4 players, seats **Red → Green → Yellow → Blue**
- 4 tokens each, start in yard
- Track is 52 cells clockwise; each color turns into a 5-cell home column, then finish
- **Exact count** required to enter finish
- **Safe squares**: every start + star cells (`8, 21, 34, 47`) — no captures
- **Block**: 2+ tokens of the same color on one track cell — immune to capture; opponents cannot land on or jump over (owner may pass / stack)
- Single opponent on a non-safe cell → **capture** (sent to yard) → **extra roll**
- Finishing a token → **extra roll**
- Roll **6** → **extra roll**; **three 6s in a row** → turn forfeited (third 6 unused)
- Opening a token places it on that color’s **start only** (dice is not also used to move further)

## Classic
- Leave yard only on a **6**
- Win by finishing **4** tokens

## Rush
- Leave yard only on a **6** (same as classic)
- Win by finishing **2** tokens

## Blitz
- Leave yard only on a **6** (same as classic)
- Win by finishing **1** token
